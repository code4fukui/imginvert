# imginvert

画像の色を反転させたり、グレースケール、コントラスト、明るさを調整するためのシンプルなウェブツールです。

## デモ

https://code4fukui.github.io/imginvert/

## 機能

- 画像の色を反転
- グレースケールに変換
- コントラストと明るさを調整
- 編集した画像をPNGファイルとしてダウンロード

## 使い方

1.  **画像の読み込み:** ページに画像ファイルをドラッグ＆ドロップします。初回読み込み時にはデフォルトの画像が表示されます。
2.  **フィルターの調整:** スライダーとチェックボックスを使用して画像を調整します。
    -   **上のスライダー:** コントラストを調整します（0% から 500%）。
    -   **下のスライダー:** 明るさを調整します（0% から 500%）。
    -   **`invert` チェックボックス:** 色の反転を切り替えます。
    -   **`gray scale` チェックボックス:** グレースケールフィルターを切り替えます。
3.  **画像の保存:** **save** ボタンをクリックして結果をダウンロードします。
