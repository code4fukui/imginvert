# imginvert

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A simple web tool for inverting image colors and adjusting grayscale, contrast, and brightness.

## Demo

https://code4fukui.github.io/imginvert/

## Features

- Invert image colors
- Convert to grayscale
- Adjust contrast and brightness
- Download the edited image as a PNG file

## Usage

1.  **Load an image:** Drag and drop an image file onto the page. A default image is provided on first load.
2.  **Adjust filters:** Use the sliders and checkboxes to modify the image.
    -   **Top Slider:** Controls contrast (0% to 500%).
    -   **Bottom Slider:** Controls brightness (0% to 500%).
    -   **`invert` checkbox:** Toggles color inversion.
    -   **`gray scale` checkbox:** Toggles the grayscale filter.
3.  **Save the image:** Click the **save** button to download the result.
